# ChatGPT installation

This package follows the Agent Skills structure: a folder containing `SKILL.md` plus supporting resources.

## Upload

1. Zip the repository/folder.
2. In ChatGPT, open the Skills area available to your account/workspace.
3. Choose to create/upload a Skill.
4. Upload the zip.
5. Review the detected instructions and resources.
6. Test with a known business journey before using it for production operational decisions.

## Suggested first test

> Use the AI-Operable Product skill. The business journey is TD Promotion. Assess whether the journey is AI-operable. First tell me which evidence sources you can inspect and what each source can establish.

## Connected data

The Skill can only use tools/apps/connectors already available under the user's or workspace's permissions. The Skill does not grant additional access by itself.
