# Claude installation

## Claude Code — project skill

This repository includes:

```text
.claude/skills/ai-operable-product/SKILL.md
```

Clone/copy the repository into the project where Claude Code should discover the skill.

## Claude Code — personal skill

Copy the skill into your personal Claude skills location if you want it available across projects.

## Claude.ai

Package the skill folder and supporting resources for custom Skill upload where that capability is available.

## Important

The Skill does not itself grant access to repositories, observability, databases, or SaaS systems. Tool/MCP/connector permissions remain separate and must be configured in the environment.
