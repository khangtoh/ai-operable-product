# AI-OPERABLE DONE

Use these as acceptance criteria for the operating surface.

| Criterion | Primary primitives | Core test |
|---|---|---|
| Outcome measurable | Outcome Intent | Can production evidence determine whether the intended outcome happened? |
| Journey observable | Journey Context, Workflow Map | Can the customer's path and current/historical journey state be reconstructed? |
| Failure explainable | Journey Context, Workflow Map, Recovery Path | Can we explain what failed, where, why, and its business effect? |
| Recovery designed | Recovery Path, Workflow Map | Is recovery designed rather than improvised? |
| Actions governed | Policy Boundary, Safe Actions | Are allowed actions explicit, bounded, auditable, and policy-constrained? |
| Support enabled | Cross-cutting | Can support understand and remediate the customer's problem without reverse-engineering the system? |
| Learning feeds back | Feedback Loop | Does production experience change future behavior? |

Results: PASS, PARTIAL, FAIL, UNKNOWN.
